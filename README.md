# LINQ in C# — API

## How to run

```bash
dotnet run
```

The program runs the 5 required queries and prints the results. Query 4
asks for a search term via console input. The bonus section at the end
calls the Open Library API and needs an internet connection.

## Requirements

- .NET 8 or later

## Structure

```
linq-training/
├── Program.cs           # Entry point — runs all 5 queries + bonus
├── src/
│   ├── Models/           # Book
│   └── Data/              # GetBooks() sample dataset
```
